# Stories — index (kept by 1141336 Story Team)

Teera is the author. 1141336 keeps the files, finds gaps and proposes ideas; it never decides canon.
Each NPC's story lives next to the rest of the character: `docs/characters/<id>/story.md`.
World-level stories live here in `docs/stories/`.

Status ladder: gathered → draft → approved → locked.
- gathered = collected from existing docs by 1141336, not reviewed by Teera in this format yet.
- draft = Teera is working on it.
- approved = Teera says OK; 1141201 (Card Team) may use it.
- locked = never change without Teera saying so.
