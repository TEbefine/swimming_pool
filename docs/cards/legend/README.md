# Legend card: The Creator (1 of 1)
- `creator-orbit.html`: the finished live card (open in a browser). Self-contained, ~1 MB.
- `creator-orbit.template.html`: source with `__PLACEHOLDER__` slots; assets are injected as base64 by a small build script (see `docs/cards/card-tiers.md`).
- `planets/`: the six final planet cut-outs. `creator_*`: the Creator art and masks. `space_background.png`: the sky.
- `material/`: WebGL frame material (`glmat.js`), surface maps (`material_maps.py`), fonts, maps.
- `tools/`: planet cut-out scripts.
Full design record: `docs/cards/card-tiers.md` (Legend section). Summary: `AI_CONTEXT.md` → C-LEG-01.
