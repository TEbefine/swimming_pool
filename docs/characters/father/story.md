# Father Kang — the old King's guard — story

**Role:** Quiet fisherman; secretly a former royal guard of the House of Wol

## Canon
Only what Teera's docs already say. Lines marked (draft) were proposals in the source doc.

- Early forties. Quiet, gruff, gentle with his family, proud and honest, bad at bargaining.
- Fishes because a soldier's skill would be noticed. A fisherman's clothes, a soldier's body.
- An old spear scar across one palm (Magistrate Nam notices it in Path B). "Old work. I carried heavy doors for a big house, once."
- Teaches: "Don't pull when it bites. Pull when it turns." Tells the frog-in-the-well story.
- Path B: wins with Palace Form, then is jailed. Chapter 1: kneels and says "Jeoha".
